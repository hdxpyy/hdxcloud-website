# HDXCLOUD — Asset Placement Guide

Drop your brand assets into the following paths. The website references
these filenames directly. If a file is missing, the component falls back
gracefully — but for a polished site, provide every file below.

## Required

- `public/logo/hdxcloud-logo.png`
  Your official HDXCLOUD logo (transparent PNG, square, at least 512×512).

- `public/favicon.ico`
  Favicon (32×32 or 64×64 ICO).

- `public/og-image.jpg`
  Social preview image (1200×630 JPEG, under 300 KB).

## Banner (optional but recommended)

- `public/banner/hdxcloud-banner.jpg`
  Wide banner used for promotional blocks (recommended 1600×600 JPEG).

## Hero Backgrounds (up to 5)

Place up to five images at:

- `public/images/backgrounds/bg-1.jpg`
- `public/images/backgrounds/bg-2.jpg`
- `public/images/backgrounds/bg-3.jpg`
- `public/images/backgrounds/bg-4.jpg`
- `public/images/backgrounds/bg-5.jpg`

Recommendations:
- 1920×1080 JPEG, quality 80, under 400 KB each.
- Dark or muted imagery works best — the hero applies dark overlays.
- Keep the focal point near the centre so cropping is safe on mobile.

If you only have one image, duplicate it as bg-1 through bg-5 to keep the
slideshow working until you replace them.
